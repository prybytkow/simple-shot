# App assets

Place application icons here. They are copied to `dist/main/assets/` during build.

| File        | Use |
|------------|-----|
| `icon.png` | Tray icon (PNG, e.g. 32×32 or 256×256) |
| `icon.ico` | Windows app/installer icon (multi-size .ico recommended: 16×16, 32×32, 48×48, 256×256) |

If you only have a PNG, you can generate an ICO (e.g. with an online tool or ImageMagick) for the installer.
